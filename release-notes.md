# Seojae 1.1.0

Initial public release of Seojae (서재), a theme for Korean academic writing.

- Warm light and muted dark palettes.
- Embedded Nanum Myeongjo Regular/Bold and local Times New Roman for Latin text.
- Optional Style Settings controls for reading width, density, paragraph spacing and footnote size.
- Dedicated reference-note hanging indents and A4-oriented print CSS.

국문 논문을 위한 서재 테마의 첫 공개 릴리스입니다. 한글 나눔명조와 영문 Times New Roman, 밝은/어두운 모드, 읽기 밀도와 본문 너비 조절을 제공합니다.

Download **both `theme.css` and `manifest.json`** into `<vault>/.obsidian/themes/Seojae/`, then select Seojae in Settings → Appearance. Community directory installation will be available only after the directory accepts and publishes the entry.

The minimum version declared by the manifest is Obsidian 1.10.6. Preview verification used Obsidian 1.13.7 CSS; native editor/IME behavior, PDF pagination, mobile and the minimum supported version have not yet been directly tested. Screenshots show a rendered sample rather than a live vault.

Theme: MIT. Embedded Nanum Myeongjo: SIL OFL 1.1. Times New Roman is not included.
